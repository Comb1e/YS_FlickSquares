# 元素弹球小游戏  
有四种元素：雷，冰，火，水。开始游戏时默认为火  
## 按键说明：  
WASD：前左后右移动  
1：切换到雷  
2：切换到水  
3：切换到火  
4：切换到冰  
（上述切换有1s的限制会先切换角色，球会在与反弹板接触后切换元素）  
## 玩法说明：  
一个方块有两滴血，有六种不同的方块，包含上述四种元素，无元素，以及冻结状态方块，还剩一滴血时会产生裂痕，血量清零则消失  
若方块与弹球碰撞时不产生元素反应则扣除一滴血，若方块无元素则赋予其弹球元素，若方块为冻结状态则消除相邻所有冻结状态方块，此处相邻可以递推。  
第二层的方块在第一层方块被摧毁后将掉下来。  
若三次未接住弹球则失败。  
## 元素反应说明：  
雷水：碰撞方块扣除两滴血，相邻方块扣除两滴血，间隔一个方块的距离扣除一滴血  
雷火：碰撞方块扣除两滴血，相邻方块扣除两滴血  
雷冰：碰撞方块扣除两滴血，弹球不反弹  
水火：碰撞方块扣除两滴血  
水冰：碰撞方块不扣血，保留原始元素，将相邻相同元素方块切换为冻结状态（3s），此处相邻可以递推  
火冰：碰撞方块扣除两滴血  
球与板：一方为水一方为冰时将让球停住，重新发球  
  
玩法来自某二字游戏的一次活动，22年底做的初版
